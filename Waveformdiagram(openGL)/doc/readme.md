开始 / 暂停

清空数据

调整刷新间隔

调整最大显示点数

调整 Y 轴范围

5 个通道显示开关

通道颜色可单独配置

网格开关

游标读数

自动缩放 X 轴

自动缩放 Y 轴

鼠标滚轮缩放 Y 轴

Ctrl + 鼠标滚轮缩放 X 轴

左键拖动平移波形
